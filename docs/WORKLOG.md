### B1 動態難度技術細節
```
interval = max(600, 1400 - floor(score / 60) * 40)  [ms]
```
- 初始：1400ms（每 1.4 秒生成一個字母）
- 每累積 60 分（=一枚核彈充能量）縮短 40ms
- 最快：600ms（需要約 score 1200 的高分局才達到）
- 每次命中後立即重新計算（讓難度曲線即時響應）

### B2 字元難度計分技術細節
```
gainedScore = round((10 + combo × 2.5) × difficulty_multiplier)
```
| 字元類型 | 倍率 | 範例（combo=5） |
|---------|------|----------------|
| 小寫字母（a-z） | 1.0x | (10 + 12.5) × 1.0 = **23 分** |
| 數字 / 大寫（0-9, A-Z） | 1.5x | (10 + 12.5) × 1.5 = **34 分** |
| 符號（!@#... 等） | 2.0x | (10 + 12.5) × 2.0 = **45 分** |

### 模組化架構說明
新建 `game/` 目錄，為長期可維護性奠基：
```
game/
├── constants.js    # 全域常數（CHAR_SETS、KEYBOARD_LAYOUT 等）
├── audio.js        # AudioEngine（Web Audio API 音效）
├── ai-pilot.js     # AIPilot（威脅評估、決策循環）
├── keyboard.js     # VirtualKeyboard（鍵盤構建、AI Gaze）
├── a11y.js         # A11yManager（無障礙模式）
├── htmx-bridge.js  # HtmxBridge（HTMX 事件橋接）
├── static-host.js  # 靜態主機 fallback（C1 已修正）
└── engine.js       # TypingGame 主引擎（整合所有子模組）
```
- 瀏覽器透過 `game.js`（原始 CJS 格式，含本次所有改善）運行
- `game/` 模組為 ES Module 重構版本，供未來進一步拆分使用
- 測試腳本繼續 `require('./game.js')` 維持相容性

## 🗓️ 今日里程碑與詳細任務進度

### 1. 遊戲核心引擎與極致輕量化架構
- **Web Audio API 零外部資源音效引擎**：
  - 捨棄外部音效 MP3/WAV 檔案，改以原生音訊振盪器（Oscillator）即時合成：雷射發射音、擊爆音、警報音、EMP 低頻蓄力與重低音震波。
- **SVG 動態砲台與雷射繪製**：
  - 底座砲台依據鎖定目標座標即時計算旋轉角度（$\theta = \arctan2(\Delta y, \Delta x)$），雷射光束高能流光連擊。
- **全鍵盤標準字元庫**：
  - 支援全小寫 `a-z`、大寫 `A-Z`、數字 `0-9` 及 32 種全鍵盤特殊標點符號，按高度與速度動態賦予威脅權重。

### 2. HTMX 伺服器端渲染與即時排行榜
- **原生 Node.js 零外部套件依賴**：
  - 移除 Express/npm 依賴，以原生 `node:http` 及 `node:fs` 打造輕量伺服器，啟動時間 < 50ms。
- **HTMX 無重載成績提交通訊**：
  - 遊戲結束後彈出呼號輸入框，利用 HTMX `hx-post="/api/score"` 與 `hx-target="#leaderboard-container"` 完成動態置換。
  - 後端持久化至 `scores.json`，並為新戰績賦予霓虹發光跳動特效（`.highlight-row`）。

### 3. 🤖 AI 副駕駛（Auto-Pilot）與 60% 賽博虛擬鍵盤
- **三段式 AI 人格演算法**：
  - 🟢 **ROOKIE BOT**：新手模式（反應延遲 220～320ms，88% 命中率，帶有手滑抖動模擬）。
  - 🟡 **CYBER PRO**：老兵模式（反應延遲 90～150ms，98% 命中率）。
  - 🔴 **AGI GOD**：神級機魂（反應延遲 30～55ms，100% 命中率，極速全自動攔截）。
- **實體 60% 機械虛擬鍵盤與 AI 視覺凝視（AI Gaze）**：
  - 刻劃實體按鍵外框、主標籤與次要標籤。
  - AI 決策時在鍵盤上即時跳躍紅色/霓虹準星；遇到大寫或 Shift 符號時，實體鍵盤的左右 <kbd>Shift</kbd> 鍵同步點亮激發。
  - 支援熱鍵 <kbd>Tab</kbd> 鍵在玩家手動操作與 AI 接管之間即時無縫切換。

### 4. ⚡ EMP 全域殲滅核彈機制
- **充能與庫存規則**：
  - 玩家每累積獲得 **60 分** 自動充能 1 枚 EMP 核彈（上限 2 枚）。
  - 空白鍵在充能完畢時呈現呼吸流光跑馬燈提示，搭配 HUD `[⚡][⚡]` 徽章。
- **引爆震撼效果**：
  - 按下 <kbd>Space</kbd> 即刻引爆，觸發雙同心衝擊波與全螢幕目標雷射射擊，瞬間肅清全場。
  - AI 巡航模式具備「危急自主決策」，目標過載或逼近防線時自動拍下核彈解危。

### 5. 👁️ 長輩友善與無障礙（A11y）大字模式
- **視覺與反應最佳化**：
  - 依據 WCAG AAA 高對比規範，頂部與開場提供切換開關，狀態使用 `localStorage` 自動記憶。
  - 目標字元節點放大至 **64px 巨幅框體**，字級提升至 **`2.3rem` 超大加粗字體**。
  - 虛擬鍵盤主字母擴增至 **`17px`**、Shift 組合符號增強為 **`14px 亮金高對比色`**。
  - 下落速度提供 15% 溫和微調減壓，降低長輩挫折感。
- **微小標點符號中文防呆標註**：
  - 針對長輩視力容易混淆的標點符號（`,`, `.`, `;`, `:`, `'`, `"`, `~`），目標泡泡自動附加微型正體中文標註（如 `[逗號]`、`[句號]`、`[分號]`），徹底避免辨識困擾。

### 6. 🎁 長輩初學三大守護寶物（Zero-Frustration Starter Pack）
為避免長輩初學時因快速碰底引發挫折感，無障礙模式開局預設配發三大保命寶物：
1. ⚡ **寶物一：滿裝 3 枚 EMP 保命核彈**（開局直接擁有 3 發全清底牌，手忙腳亂時按空白鍵即化險為夷）。
2. 🛡️ **寶物二：3 層失誤免死護盾**（前 3 次字母碰底由神聖護盾 100% 抵擋吸收，血條 0 損耗）。
3. 💡 **寶物三：鍵盤智慧引導明燈**（追蹤全場最靠近底線的最危險目標，在虛擬鍵盤對應鍵位發出高辨識綠色呼吸光暈；若為大寫字母，Shift 鍵與字母鍵同步亮燈引導）。

### 7. 🇹🇼 全面正體中文介面規範化
- 審查全介面語言，確立核心原則：**除了鍵盤必要之英文字母與熱鍵外，其餘說明、雷達指示與按鈕皆為正體中文**。
- 將 `AI PILOT` $\to$ `AI 副駕駛`、`LOCK` $\to$ `鎖定`、`AI GAZE` $\to$ `AI 凝視`、`SCORE` $\to$ `得分`、`COMBO` $\to$ `連擊`、`HEALTH` $\to$ `生命` 等徹底正體中文化。
- 修正虛擬鍵盤主副字型大小寫對應問題，主鍵（大字）顯示大寫、副鍵（小字）顯示小寫，兩者邏輯完全一致。

### 8. 📐 HUD 排版防擠壓與全裝置響應式設計（Responsive Adaptation）
- **診斷問題**：舊版 HUD 將 8 個項目緊密排在單一 flex 容器，中文字在 1000px 寬度內產生垂直折行（如 `得\n分`、`連\n擊`）；排行榜數據長短不一，未對齊導致凌亂。
- **重構與落實**：
  - HUD 拆分為 `.hud-stats-group`（左戰況）與 `.hud-controls-group`（右控制項）。
  - 套用 `white-space: nowrap; flex-shrink: 0;` **杜絕任何文字折行**。
  - 精簡文字標籤（`生命值` $\to$ `生命`、血條縮為 80px），大幅釋放空間至 ~835px。
  - 排行榜全面採用 `font-variant-numeric: tabular-nums;`，排名置中（44px）、呼號靠左自動縮略、數值（得分、連擊、命中率）一律靠右對齊。
  - 建立 3 階響應式斷點（寬螢幕、平板中型 769~1150px、手機小螢幕 $\le$ 768px 自動轉為上下雙全寬 row 呈現）。
